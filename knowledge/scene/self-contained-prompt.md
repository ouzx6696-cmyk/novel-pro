# 自包含提示词方法论

> **流程边界标注**：本文件已被 `skills/prompt.md` 与 `skills/context-pack.md` 硬引用为 Prompt 自检协议（九项检查）的权威源，属于**流程规则而非纯知识**。修改本文件会改变 prompt-crafter 的默认创建行为，必须同步核对 `skills/prompt.md`、`skills/context-pack.md`、`templates/settings/context-pack.md` 与 `agents/prompt-crafter.md`；按 `docs/framework-overview.md` 的扩展机制维护。

本文档定义单章 Prompt（`prompt_contract: 4`）的自包含性标准与实现方法。目标是：每一份 `prompts/vol-N-ch-M.md` 交付给 writer 时，writer 不需要任何外部参考即可独立完成本章创作。本文档供 prompt-crafter 使用，与 `skills/prompt.md` 的 Prompt 模板配套；自检协议（九项检查）是写完后的检查，`skills/prompt.md` 的「四步转化法」是写的过程，两者衔接。

## 一、问题定义

### 什么叫做"不自包含"

一段 Prompt 不自包含，指的是它包含了 writer 无法从 Prompt 自身解析的引用。这些引用指向的是 writer 拿不到的上下文。

**不自包含的典型形态**：

- **编号式引用**："承接上一章结尾的动作"、"本章是第三幕的转折点"、"如章纲所述的核心冲突"。writer 不知道上一章结尾是什么，不知道第三幕的戏剧任务是什么，看不到章纲。
- **索引式引用**："主角如人物设定中所述的性格"、"按照项目文风的要求"。writer 看不到人物设定文件，看不到文风文件。
- **标签式引用**："本章质感：冷峻克制"、"情绪方向：由低到高"。writer 得到了标签但没有得到任何可执行的内容。
- **意图式引用**："为后续剧情做铺垫"、"埋下一个伏笔"。writer 知道要"铺垫"但不知道铺垫什么、铺垫到什么程度。
- **缺失式不自包含**：叙述表面连贯，但遗漏了 writer 必须知道的关键事实：没写时间地点、没写人物此刻的物理位置、没写当前压力是什么。
- **空转式不自包含**：叙述里塞满了"展开要生动""冲突要激烈"这类放之四海皆准的抽象指令，换一章、换一场也能原样粘贴。writer 拿到了正确的形状，但没有拿到这一场、这一章独有的内容。

### 自包含 Prompt 的核心检验

**"新读者检验"**：如果一个完全没看过大纲、没读过前面章节、没看过人物设定的人，只拿着这份 Prompt，他能否写出这章？

如果能，这份 Prompt 是自包含的。如果不能，Prompt 中存在需要消除的外部引用。

## 二、三自原则

### 原则一：自说明（Self-explaining）

Prompt 自身说清本章要写的所有关键事实。所有 writer 需要知道的"什么正在发生、为什么发生、谁参与其中、此前最关键的事件是什么"，都在 Prompt 内部完整给出，不需要查找任何外部文件。

"自说明"不是"把所有设定全部复制进来"：是把**当前章实际需要的**事实嵌入。设定文件中与本章无关的内容不嵌入。

### 原则二：自闭合（Self-closing）

Prompt 内部形成完整的信息闭环。本章的起点状态（时间、地点、人物物理位置、当前信息持有、当前压力来源）和终点状态（需要完成的变化、变化后的状态）都在 Prompt 内明确。

自闭合的 Prompt 不依赖"上一章结尾"或"下一章开头"这些外部位移：它把衔接处的事实内化为 Prompt 自己的内容，不是"从上一章结尾继续"，而是"人物此刻在什么时间、什么地点、刚刚发生了什么、手上有什么、心里有什么压力"。

**前情取自真实正文**：顺序链路下，第 M 章 Prompt 创建时第 M-1 章已经验收/提交，衔接事实（上章结尾画面、情绪残留、缺口）必须从**上一章真实正文末尾**提取，不能凭规划记忆或标签推断。同幕内 prompt-crafter 读上一章全文建立质感；跨幕（本幕首章）增读上一幕的**幕末正文总结** `summaries/vol-N-act-K-1.md` 作跨幕导航（派生缓存，事实仍以正文与 `settings/` 为准）。这是「前情上下文」块的唯一来源，frontmatter 的 `preceding_source` 供审计追溯。

### 原则三：自锚定（Self-anchoring）

Prompt 中的文风指导不依赖标签和方向词（"冷峻""克制""有张力"），而是双轨锚定在具体材料上：

1. **叙述示范**：「本章故事」的叙述本身用项目声线写成。这是最强的锚，writer 直接看见这一章该有的句长、物件、停顿和克制，胜过任何形容词。
2. **逐场落点**：每场「本场声线」给出句长倾向、对白与叙述配比、感官密度、留白位置与一句样句锚点，把声线钉死在这一场的人、事、物上。

自锚定不是要求 Prompt 提供"样章"（样章由 `settings/writing-style.md` 提供，prompt-crafter 在创建时已读取并转化为叙述示范与逐场落点），而是要求文风指导是可执行的写作规则与可见的示范，而非不可操作的形容词。

## 三、各节的自包含化规则

以下规则对应 `skills/prompt.md` 中定义的 Prompt 模板（六块）。每节说明：不自包含的写法有什么问题，自包含的写法需要嵌入什么信息。

### 前情上下文

本节是承接锚，直接取自上一章真实正文。**此节必须嵌入的信息**：

- **上章结尾画面**：从上一章验收稿/定稿末尾提取 30-50 字具象画面（人物在做什么、留下什么可见证据）。不是叙事意图（"上一章主角做出了决定"），是具体画面（"主角把掌门令符压在戒律堂的桌角下，头也不回地跨出门"）。
- **读者情绪残留**：一个情绪词（不是分析），来自上一章情绪落点。没有情绪词的收束是断接。
- **上章留下的缺口**：读者期待但还没发生的事，1 句；与章纲 `reader_effect`/`ends_with` 核对，保证承接的不是规划设想而是正文实际留下的。

### 角色初始状态

本节是本章开场时的人物状态快照，**此节必须嵌入的信息**（每人 2-3 句，只写本章会实际作用的）：

- **位置与身体状态**：人物此刻在哪、以什么状态存在、身上是否有伤、手里有什么。
- **已知信息**：截至上一章结束人物确定知道什么（从角色档案 `state_history` 倒读，与上一章正文核对）。
- **微习惯/小动作锚点**：一个可辨识的行为锚点，供 writer 开场时调用，避免人物漂成空壳。

角色初始状态是"状态快照"，与「人物动机与情绪」的"递进弧线"分工：快照定起点，弧线定走向。

### 本章故事（含收束与读者期待）

本节是全文的锚，用 300–500 字连贯叙述承担原来三处职责：承接现场、本章要完成的变化、收束画面。**此节必须嵌入的信息**：

- **时间锚点**：具体的时间标签（时刻、日期、或相对于最近可识别事件的时间关系）。不能只写"次日"，如果读者不知道"次日"是从哪天算起；时间跳跃较大时标明跳了多少。
- **地点锚点**：具体的地点名称和地点特征。不仅是地名，还包括这个地点此刻的物理状态（"戒律堂里只有一盏灯亮着，香炉里的灰已经冷了"）。
- **人物物理状态**：人物此刻在什么位置、以什么姿势/状态存在。正在移动还是静止？身上是否有伤？手里是否有东西？
- **上文收束**：把前一章结尾的核心事实内化为本章的起点。"上一章结尾主角被宣布禁足"要写成"主角在戒律堂偏殿内，手腕上的灵力枷锁是一炷香前被长老亲手戴上的"。
- **即时压力**：人物此刻面对的最紧迫的问题。不是"面临着巨大的压力"，而是"她必须在半个时辰内说服林小婉不要翻供，否则执法队到时会直接提人"。
- **本章路径**：本章要走的完整一段路：遇到什么阻力、经过几次交锋、在哪里转向、付出什么代价。写事件走向与因果，不编排对白措辞和动作细节。
- **幕内作用与核心变化**：叙述里让变化可检验。"本章需要完成的变化：主角从此前的隐忍转为第一次公开对抗；本章结尾她做出第一个'不再藏拙'的决定"。
- **POV 限定**：明确本章的感知范围：人物能看见什么、听到什么、知道什么、不知道什么。多 POV 时在各场分别标明。
- **收束**：正文停在哪一个具体画面：人物在做什么、有什么可见的证据、留下了什么新状态。不是叙事意图（"为下一章做铺垫"），是具象画面。
- **读者期待**：回应、加深或转移的具体问题。不是"回应读者对主角实力的期待"，而是"读者从第 N 章就在等主角不再装弱的那一刻：本章兑现这个等待，但兑现的方式是主角被迫而非主动、代价是暴露而非掌控"。

### 人物动机与情绪

本节把原「人物发动机」从此刻状态快照升级为递进弧线。**每个出场人物必须嵌入**：

- **起点**：他进场时想要什么（表层目标，具体到本章可检验）、最怕发生什么、已知什么、误判什么、筹码和底线在哪、在关系中的位置（"他们是师徒，但自从上个月那件事后，她每次和师父说话都在想：他到底知不知道真相"）。
- **施压点**：本章哪一个事实或压力会撬动他：新信息、新压力、筹码失效，还是某个误判被现实纠正。信息差在这里起作用：谁知道、谁不知道、谁在误判。
- **转向与落点**：他的目标或情绪在哪一刻变、变成什么、转向后剩下什么。变化必须来自事件后果与人物反应，不是性格标签，也不是抽象的情绪命名。
- **情绪线**：全章情绪从什么基调起、在哪一场升或压、收在什么温度，对应本章节奏型（哪里密集推进、哪里放缓换气）。这条线锁定全章统一声线，防止逐场落点漂移。

### 场景展开（每个场景）

每场含四件：场景叙述、行动脉络、本场怎么写、本场声线。**此节必须嵌入的信息**：

- **场景叙述**（3–6 句连贯叙述）：谁带着什么进场、想要什么、被什么挡住、双方怎样试探施压、什么改变判断、付出什么代价、留下什么新局面。
- **行动脉络**（六环节一句成链）：入场状态 → 目标与阻力 → 行动与反制 → 转折与选择 → 可见结果 → 下一步触发。锁因果，不锁措辞。阻力的具体形式要写清："对手通过控制考核流程来阻止她，他不需要打败她，只需要让她在规定时间内拿不到足够的分数"。转折要写清因何而触发（新信息/新压力/筹码失效），代价必须在本章可见。可见结果写变化的方向和程度（"从信任到怀疑""从平等博弈到一方占据主动"）。下一步触发写清本场结果如何制造下一场入场条件。
- **本场怎么写**（2–4 条具体展开指导）：针对这场戏的性质（对峙/试探/日常/追逐/独处等）从 context-pack 技法转化而来。规则：
  - 落到本场的人、事、物上，换成这一场的动作、对白、感官设计，不点名方法名，不出现"张力""生动""真实"这类空转词。
  - 多场之间、多章之间不得复诵同一条指令原文：每一场的指导必须与这一场的具体内容绑定，能看出是这一场专属。
  - 以正向操作指令表述；诊断标签、规则名、坏句清单永不进入 Prompt（反AI 隔离铁律）。
- **本场声线**：这一场的句长倾向、对白与叙述配比、感官密度、何处留白（哪些话直说、哪些只给动作和停顿），加一句样句锚点（从 writing-style.md 基准样章选取或按其声线原创）。声线指令必须是可操作的写作规则，不是形容词。

### 必守事实与边界

**此节必须嵌入的信息**：

- **信息差变化**：开场信息差（谁知道什么 ↦ 谁不知道什么）→ 结尾新信息差（驱动下一章）。这是本章信息流动的可检验记录，来源是章纲 `info_gap`；缺了这一行，writer 无从判断"谁在瞒谁、读者该急什么"。
- **必须发生**：通过人物行动交付的变化。描述人物做了什么导致什么改变，不是"本章需要出现的剧情点"。
- **相关事实**：本章实际需要的身份、能力、资源、信息状态。不是人物设定的完整清单，只列本章会被用到或会影响行动的事实。
- **保留边界**：本章不能动的事实清单，具体到事实本身："主角的真实身份不能在任何人面前暴露""A 和 B 的联盟关系不能被任何第三方知道"。不是"会影响后续承接"这个意图。

## 四、幕级上下文的自包含化

prompt-crafter 创建 Prompt 时拥有幕级的完整理解。但这些幕级理解在写入单章 Prompt 时，必须从"幕级标签"转化为"此刻事实"。

### 卷阶段上下文

卷的当前阶段信息，在 Prompt 中不应以"本卷已经进入第三幕"的形式出现，而应转化为：

- 嵌入「本章故事」：把卷的进度转化为本章的起点条件："迄今为止发生的关键变化：A 已成立、B 已成立、C 尚未发生。主角与反派的关系阶段：公开对立但尚未正面交手。"
- 嵌入「人物动机与情绪」：人物目标的阶段化：如果卷初的目标是"复仇"，本章的目标是"复仇路径上的第几步"。
- 嵌入「必守事实与边界」：哪些卷级事实在本章中作为约束条件：不写"根据卷纲"，写具体的事实内容。

### 幕任务的自包含化

幕的戏剧任务（dramatic task）不应以"本幕的戏剧任务是 X"的形式出现在 Prompt 中，而应转化为：

- 在「本章故事」中说明：本章在这个更大任务中属于哪个环节：建立条件、压力测试、还是兑现。
- 在「场景展开」中体现：场景设计是否在服务这个幕级任务；如果某个场景与幕任务无关，它可能是冗余的。

### 跨章承接的自包含化

章与章之间的承接，不在 Prompt 中写"承接上一章"，而是：

- 每章「前情上下文」直接嵌入上一章**真实正文**的收束画面、情绪残留与缺口（顺序链路保证上一章已验收/提交；这是唯一来源，不能用规划记忆代替）。
- 每章「角色初始状态」从角色档案 `state_history` 倒读重建，与上一章正文结尾核对。
- 如果前一章的重要信息在几章之后仍然影响当前章（如一个秘密被揭露后持续改变人物关系），在「人物动机与情绪」中标注这个信息的持续影响，而非引用"如第 N 章所揭示的"。

## 五、自检协议

prompt-crafter 完成每份 Prompt 后，依次执行以下九项检查：

1. **新人测试**：假设自己完全没有读过任何大纲、设定、前文。从 Prompt 的第一个字读到最后一个字。有任何地方看不懂、需要"去查一下"或"根据前后文推断"的吗？有，则不自包含。

2. **引用扫描**：搜索 Prompt 中所有包含以下模式的表述并替换为具体事实：
   - "上一章/前一幕/第N章/之前的章节"
   - "根据设定/章纲/大纲/卷纲"
   - "按照人物设定中的"
   - "如前所述的/如前所述"
   - "为后续/为后面"（作为独立意图而非附带说明）
   - 任何章/幕/卷的编号

3. **前情上下文落地检查**：「前情上下文」三件（上章结尾画面/情绪残留/缺口）是否都能在 `preceding_source`（上一章真实正文末尾）找到对应文本？同幕章的画面是否与上一章全文的收束一致；跨幕首章是否与幕末正文总结 `summaries/` 的幕末承接帧、上一章真实结尾核对一致？画面是具体场景而非叙事意图？情绪是一词而非分析？缺口与章纲 `reader_effect` 一致？

4. **承接闭环验证**：本章「本章故事」的起笔是否可以完全由「前情上下文」的收束画面解释？如果存在一个"承接断裂"，该事实尚未在 Prompt 链中建立，需要嵌入。

5. **状态具体性检验**：逐节检查所有描述是否具体：
   - 时间：是否有具体的时间标签？
   - 地点：是否有具体的地点名称和物理特征？
   - 人物状态：是否有物理位置、身体状态、信息持有？（「角色初始状态」每人是否含位置/状态/已知/持有物/微习惯）
   - 压力：是否有具体的时间窗口、具体后果？
   - 目标：是否有具体的、可在本章内检验的成败标准？

6. **可执行性检验**：writer 拿着这份 Prompt，每一段正文应该能找到对应的 Prompt 信息支撑。如果 Prompt 中有任何内容写了但 writer 不知道如何在正文中执行，该内容需要更具体的指令或删除。

7. **叙述连贯与递进检验**：「本章故事」是否连贯可读、是叙述而非 bullet 堆砌；每个出场人物在「人物动机与情绪」中是否有完整的起点、施压点、落点；「角色初始状态」与「人物动机与情绪」是否一致（起点快照与弧线起点不打架）；全章情绪线是否明确。

8. **信息差检验**：「必守事实与边界」是否含信息差变化（开场 → 结尾）？是否与章纲 `info_gap` 一致、与「角色初始状态」的已知信息不矛盾？

9. **技法溶解检验**：每场「本场怎么写」是否具体到场次的人、事、物，无方法名、无"张力/生动/真实"类空转词；多场之间、多章之间无逐字复诵的抽象指令；「本场声线」每场都有落点且与该场内容绑定。

## 六、与既有契约的关系
