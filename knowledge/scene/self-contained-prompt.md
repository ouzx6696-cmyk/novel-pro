# 自包含提示词方法论

本文档定义单章 Prompt 的自包含性标准与实现方法。目标是：每一份 `prompts/vol-N-ch-M.md` 交付给 writer 时，writer 不需要任何外部参考即可独立完成本章创作。本文档供 prompt-crafter 使用，与 `skills/prompt.md` 的 Prompt 模板配套。

## 一、问题定义

### 什么叫做"不自包含"

一段 Prompt 不自包含，指的是它包含了 writer 无法从 Prompt 自身解析的引用。这些引用指向的是 writer 拿不到的上下文。

**不自包含的典型形态**：

- **编号式引用**："承接上一章结尾的动作"、"本章是第三幕的转折点"、"如章纲所述的核心冲突"。writer 不知道上一章结尾是什么，不知道第三幕的戏剧任务是什么，看不到章纲。
- **索引式引用**："主角如人物设定中所述的性格"、"按照项目文风的要求"。writer 看不到人物设定文件，看不到文风文件。
- **标签式引用**："本章质感：冷峻克制"、"情绪方向：由低到高"。writer 得到了标签但没有得到任何可执行的内容。
- **意图式引用**："为后续剧情做铺垫"、"埋下一个伏笔"。writer 知道要"铺垫"但不知道铺垫什么、铺垫到什么程度。
- **缺失式不自包含**：字段表面没有引用，但遗漏了 writer 必须知道的关键事实——没写时间地点、没写人物此刻的物理位置、没写当前压力是什么。

### 自包含 Prompt 的核心检验

**"新读者检验"**：如果一个完全没看过大纲、没读过前面章节、没看过人物设定的人，只拿着这份 Prompt，他能否写出这章？

如果能，这份 Prompt 是自包含的。如果不能，Prompt 中存在需要消除的外部引用。

## 二、三自原则

### 原则一：自说明（Self-explaining）

Prompt 自身说清本章要写的所有关键事实。所有 writer 需要知道的"什么正在发生、为什么发生、谁参与其中、此前最关键的事件是什么"，都在 Prompt 内部完整给出，不需要查找任何外部文件。

"自说明"不是"把所有设定全部复制进来"——是把**当前章实际需要的**事实嵌入。设定文件中与本章无关的内容不嵌入。

### 原则二：自闭合（Self-closing）

Prompt 内部形成完整的信息闭环。本章的起点状态（时间、地点、人物物理位置、当前信息持有、当前压力来源）和终点状态（需要完成的变化、变化后的状态）都在 Prompt 内明确。

自闭合的 Prompt 不依赖"上一章结尾"或"下一章开头"这些外部位移——它把衔接处的事实内化为 Prompt 自己的内容：不是"从上一章结尾继续"，而是"人物此刻在什么时间、什么地点、刚刚发生了什么、手上有什么、心里有什么压力"。

### 原则三：自锚定（Self-anchoring）

Prompt 中的文风指导不依赖标签和方向词（"冷峻""克制""有张力"），而是锚定在具体的技术要求上：句长偏好、对白与叙述的比例、禁用的句式类型、感官描写的密度。

自锚定不是要求 Prompt 提供"样章"（样章由 `settings/writing-style.md` 提供，prompt-crafter 在创建时已读取并转化为本章的技术指令），而是要求文风指导是可操作的写作规则，而非不可操作的形容词。

## 三、各字段的自包含化规则

以下规则对应 `skills/prompt.md` 中定义的 Prompt 模板。每个字段说明：不自包含的写法有什么问题，自包含的写法需要嵌入什么信息。

### 承接现场

**此字段必须嵌入的信息**：

- **时间锚点**：具体的时间标签（时刻、日期、或相对于最近可识别事件的时间关系）。不能只写"次日"，如果读者不知道"次日"是从哪天算起。如果时间跳跃较大，需要标明跳了多少。
- **地点锚点**：具体的地点名称和地点特征。不仅是地名，还包括这个地点此刻的物理状态（"戒律堂里只有一盏灯亮着，香炉里的灰已经冷了"）。
- **人物物理状态**：人物此刻在什么位置、以什么姿势/状态存在。正在移动还是静止？身上是否有伤？手里是否有东西？
- **上文收束**：嵌入前一章结尾的核心事实——不是"上一章结尾发生了什么"，而是把那个结尾内化为本章的起点。"上一章结尾主角被宣布禁足"→"主角在戒律堂偏殿内，手腕上的灵力枷锁是在一炷香前被长老亲手戴上的"。
- **即时压力**：人物此刻面对的最紧迫的问题是什么。不是"面临着巨大的压力"，而是"她必须在半个时辰内说服林小婉不要翻供，否则执法队到时会直接提人"。

### 本章要完成的变化

**此字段必须嵌入的信息**：

- **幕内作用的自包含化**：不是"本章是第三幕中承上启下的转折章"，而是"本章需要完成的变化：主角从此前的隐忍转为第一次公开对抗。此前她一直靠隐藏修为保护自己和身边人，本章结尾她做出第一个'不再藏拙'的决定"。
- **核心变化的具体化**：变化必须是可检验的——"主角的心态发生变化"不具体；"主角在本章结尾做出选择X，这个选择意味着她放弃了之前的策略Y"是具体的。
- **读者期待的具体化**：不是"回应读者对主角实力的期待"，而是"本章回应的问题：读者从第N章就在等主角不再装弱的那一刻——本章兑现这个等待，但兑现的方式是主角被迫而非主动、代价是暴露而非掌控"。
- **POV 的限定**：明确本章的感知范围——人物能看见什么、听到什么、知道什么、不知道什么。如果本章有多个 POV，在对应场景中分别标明。

### 人物发动机

**此字段必须嵌入的信息**：

每个出场人物的状态是**此刻的**，不是人物设定的摘要。嵌入：

- **表层目标**：人物在本章中具体想达成什么。不是"她想变强"，而是"她想在今天的宗门考核中不被淘汰，因为淘汰意味着被逐出内门，失去接近仇人的唯一路径"。
- **深层恐惧**：不是"她害怕失去"，而是"她在本章中最怕发生的具体场景是什么，以及为什么这个场景对她来说不可承受"。
- **已知与误判**：人物此刻掌握的信息的真实状态。不是"她知道真相"，而是"她知道A、B，但她不知道C，并且她误以为D是E"。如果有信息差，这个信息差如何影响她本章的行动。
- **筹码与底线**：人物此刻可以动用的资源（不只是钱/权力——包括人脉、信息、技能、时间窗口），以及什么条件会让她放弃当前策略。
- **在关系中的位置**：人物此刻与本章其他出场人物的关系状态。不是"他们是师徒"，而是"他们是师徒，但自从上个月的那件事后，她每次和师父说话都在想：他到底知不知道真相"。

### 场景推进 — 每个场景

**此字段必须嵌入的信息**：

- **入场状态**：不止是"谁在什么地方"。包括：人物入场时已有的情绪基调（来自入场前刚刚发生的事）、入场时的身体状态、入场时的信息状态（刚知道什么/刚经历了什么）。
- **目标与阻力**：双方的具体目标，以及阻力的具体形式。不是"对手阻止她"，而是"对手通过控制考核流程来阻止她——他不需要打败她，只需要让她在规定时间内拿不到足够的分数"。
- **转折与选择**：转折因什么而触发——是因为新信息、新压力、还是某个筹码的失效？选择的具体代价是什么——代价必须在本章可见，不能推到后面。
- **可见结果**：关系、信息、资源、风险或局势的具体变化。不能写"关系发生了变化"，要写变化的方向和程度——"从信任到怀疑"、"从平等博弈到一方占据主动"。
- **下一步触发**：本场景的结果如何具体地制造了下一个场景的入场条件。

### 必守事实与边界

**此字段必须嵌入的信息**：

- **必须发生**：写的是"通过人物行动交付的变化"，不是"本章需要出现的剧情点"。区别在于：前者描述人物做了什么导致什么改变；后者描述作者想让读者看到什么。
- **相关事实**：列出当前章实际需要的身份、能力、资源和信息状态。不是人物设定的完整清单——只列本章中会被用到或会影响行动的事实。
- **保留边界**：列出哪些事实本章不能动——不是"会影响后续承接"这个意图，而是具体的事实清单："主角的真实身份不能在任何人面前暴露"、"A和B的联盟关系不能被任何第三方知道"。

### 收束画面

**此字段必须嵌入的信息**：

收束画面必须是具体的、可见的动作、证据、选择或状态。不能是叙事意图。

- 不自包含："为下一章做铺垫"、"留下悬念"、"角色关系发生微妙变化"
- 自包含的要求：描述一个具象的画面——人物在做什么、有什么可见的变化、留下了什么可见的证据。下一章的承接现场会引用这个画面中的具体事实。

### 本章质感

**此字段的嵌入规则**：

质感字段的来源是 `settings/writing-style.md`，但 Prompt 中写入的不是来源引用而是提取后的技术指令：

- **声线要点**：不是"冷峻克制"，而是具体的句法偏好（"叙述句以短句为主，连续不超过三句长句"）、对白特征（"对白不直接说情绪，情绪通过动作和停顿显露"）。
- **本章节奏**：段落节奏型和感官密度。不是"紧凑"，而是"本章前1/3以密集动作推进，中间以一段静态对白降压，末尾再次加速"。
- **禁用表达**：列出本章场景类型下特别需要规避的句式/用词/写法。不引用反AI词库，而是从文风文件的禁区中提取与本章场景最相关的少数几条。
- **人物声音与留白**：指明哪些情感或判断应通过动作/沉默/空间留白传达，而不是通过内心独白或叙述说明。这是防止"AI腔"的具体防线。

## 四、幕级上下文的自包含化

prompt-crafter 创建 Prompt 时拥有幕级的完整理解。但这些幕级理解在写入单章 Prompt 时，必须从"幕级标签"转化为"此刻事实"。

### 卷阶段上下文

卷的当前阶段信息，在 Prompt 中不应以"本卷已经进入第三幕"的形式出现，而应转化为：

- 嵌入到"承接现场"和"本章要完成的变化"中：把卷的进度转化为本章的起点条件——"迄今为止发生的关键变化：A已成立、B已成立、C尚未发生。主角与反派的关系阶段：公开对立但尚未正面交手。"
- 嵌入到"人物发动机"中：人物目标的阶段化——如果卷初的目标是"复仇"，本章的目标是"复仇路径上的第几步"。
- 嵌入到"必守事实"中：哪些卷级事实在本章中作为约束条件——不写"根据卷纲"，写具体的事实内容。

### 幕任务的自包含化

幕的戏剧任务（dramatic task）不应以"本幕的戏剧任务是X"的形式出现在 Prompt 中，而应转化为：

- 在"本章要完成的变化"中说明：本章在这个更大任务中属于哪个环节——是建立条件、是压力测试、还是兑现。
- 在"场景推进"中体现：场景设计是否在服务这个幕级任务？如果某个场景与幕任务无关，它可能是冗余的。

### 跨章承接的自包含化

章与章之间的承接，不在 Prompt 中写"承接上一章"，而是：

- 每章的"承接现场"内嵌前一章"收束画面"中的具体事实。
- 如果前一章的重要信息在几章之后仍然影响当前章（如一个秘密被揭露后持续改变人物关系），在"人物发动机"中标注这个信息的持续影响，而非引用"如第N章所揭示的"。

## 五、自检协议

prompt-crafter 完成每份 Prompt 后，依次执行以下检查：

1. **新人测试**：假设自己完全没有读过任何大纲、设定、前文。从 Prompt 的第一个字读到最后一个字。有任何地方看不懂、需要"去查一下"或"根据前后文推断"的吗？有，则不自包含。

2. **引用扫描**：搜索 Prompt 中所有包含以下模式的表述并替换为具体事实：
   - "上一章/前一幕/第N章/之前的章节"
   - "根据设定/章纲/大纲/卷纲"
   - "按照人物设定中的"
   - "如前所述的/如前所述"
   - "为后续/为后面"（作为独立意图而非附带说明）
   - 任何章/幕/卷的编号

3. **承接闭环验证**：本章的"承接现场"是否可以完全由前面某章的"收束画面"解释？如果存在一个"承接断裂"——读者无法从任何已有 Prompt 中找到承接的信息来源——则该事实尚未在 Prompt 链中建立，需要嵌入。

4. **状态具体性检验**：逐字段检查所有描述是否具体——
   - 时间：是否有具体的时间标签？
   - 地点：是否有具体的地点名称和物理特征？
   - 人物状态：是否有物理位置、身体状态、信息持有？
   - 压力：是否有具体的时间窗口、具体后果？
   - 目标：是否有具体的、可在本章内检验的成败标准？

5. **可执行性检验**：writer 拿着这份 Prompt，每一段正文应该能找到对应的 Prompt 信息支撑。如果 Prompt 中有任何字段写了但 writer 不知道如何在正文中执行，该字段需要更具体的指令或删除。

## 六、与既有契约的关系

- 本文档是 `skills/prompt.md` 的方法论补充，不修改 Prompt 模板的字段结构。
- 本文档中的自检协议替代 prompt-crafter 原有的隐式判断，不新增角色或脚本门禁。
- 文风提取的来源 `settings/writing-style.md` 在 prompt-crafter 的创作上下文中已规定读取，本文档不改变这个读取规则，只规范读取后如何转化为 Prompt 内容。
- Reader 冷读协议不变：Reader 仍只读正文，首读阶段不读 Prompt 或本文档。
- `context-pack.md` 的打包来源中，本文档应被纳入第4节（场景写法工具箱）的打包范围，作为一个方法条目。
