# 文风原型索引

本目录提供文风起点，不提供作者模仿模板。原型只保留可迁移的读者体感、叙事距离、句法呼吸、对白关系、感官使用和情绪落点；不包含作者名、作品名、角色名、世界观词、标志性句子或固定剧情。

## 什么时候读取

- `volume-planner`：项目的 `settings/writing-style.md` 尚未形成，或作者明确要选择文风方向时读取本索引，再读取一个最接近的原型。
- `prompt-crafter`：不读取原型库；项目文风确认后只读取项目文件并按章提取。
- `writer`、`reader`、`anti-AI`：不直接读取原型库。writer 使用项目样章和当前 Prompt，Reader 根据实际正文判断，不把原型变成验收表。

## 调用流程

1. 先从作者想要的读者体感、题材功能、POV 和主角表达方式出发，选择一个主原型。
2. 最多选择一个辅原型。主原型决定叙事距离、句法和情绪处理；辅原型只补一项明确能力，不覆盖主原型。
3. 读取所选原型，把其中少量真正稳定、可迁移的特征改写进项目的 `settings/writing-style.md`，再用项目人物和原创场景写出样章、对照示范与声线边界。
4. 作者确认后锁定项目文风。后续 prompt-crafter 只从项目文风提取本章特征，不在每章重新套用原型。
5. 如果两套原型的 POV、句法、情绪处理或对白原则冲突，保留主原型，舍弃冲突项；不要把矛盾规则并排交给 writer。

## 提炼边界

- 删除来源印记：不保留姓名、作品术语、角色口癖、标志性比喻、独特设定和可识别句式。
- 删除机械约束：不把比例、频率、字数、标点次数或词汇阈值写成项目门禁；它们最多作为作者观察方向。
- 保留写作判断：说明人物如何注意、如何说话、如何行动、如何承受情绪，以及读者应当如何感到变化。
- 重新原创化：最终样章必须使用项目自己的角色、空间、关系和事件，不复制原型文件中的表达。

|---|---|
| 宏阔、克制、情绪留白 | `restrained-distance.md` |

| 青春、镜头感、热闹后的感伤 | `cinematic-youth.md` |
| 绵长、思辨、叙事承载思考 | `reflective-longform.md` |
| 轻松、社交喜剧、内心吐槽 | `comic-inner-voice.md` |
| 高能、荒诞比喻、动作链 | `absurd-action.md` |
| 冷静、推理、规则与证据驱动 | `analytical-system.md` |
| 冷面日常、细腻关系、暗热情绪 | `cool-surface.md` |

原型是一次性的创作起点，不是长期状态，也不改变 `settings/writing-style.md` 的权威地位。
