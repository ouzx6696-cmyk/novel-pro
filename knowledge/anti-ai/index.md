# 表达知识索引

本索引由编辑模式的 anti-AI 在 `edit.anti-ai`（全量扫描报告）与 `edit.repair`（编辑候选）两阶段按需加载，扫描同批章节、编辑只处理有证据的问题。写作模式、writer、Prompt 创建、Prompt 修复和 Prompt 审核不加载 anti-AI 工作规则。

题材文件中的优先删改、优先保留和处理口径，只在确认真实表达问题后使用。它们不是全书扫描清单，也不授权编辑自行扩大范围。

anti-AI 只修改正文里真实出现且确实损害阅读的表达问题。这里没有禁用词扫描、密度统计、等级、轮数或达标数量。无法确认是否越界时保留原文，交 Reader 复读。

知识里的句式特征和触发词仅用于理解被发现的问题，不是可复制的正文样句或替换模板。不得把规则名、坏句清单、诊断过程或加载过程回流到 Prompt 或候选正文。

题材文件统一使用“优先删改 / 优先保留 / （可选）处理口径”的结构；继承类文件只写新增内容，不重复父题材全文。

## 通用文件入口

| 入口 | 内容 | 使用者 |
|---|---|---|
| `knowledge/anti-ai/common.md` | 通用表达编辑：何时处理、怎么处理、否定排比/破折号夹注/高频解释性对照的判别，以及不处理的情况 | anti-AI（报告模式识别、编辑模式执行） |
| `knowledge/anti-ai/boundary-cases.md` | 表达编辑边界：优先保留的情况与越界判定（删除会改变信息/关系/选择、角色口癖、长句速度、题材术语等） | anti-AI（编辑模式守边界）、completion-editor（共守同一编辑边界） |
| `knowledge/anti-ai/genre/<genre_id>.md` | 题材专属的优先删改、优先保留和处理口径（按 `genre_id` 叠加，只写差异化） | anti-AI（编辑模式中按题材加载） |
