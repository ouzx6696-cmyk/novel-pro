# 写作风格（风格提示词）

本文件是项目文风的唯一权威源，**它就是项目的风格提示词**：供 prompt-crafter 每章创建 Prompt 时调用、writer 执行。volume-planner 在卷纲阶段与作者共同形成，作者确认后锁定；后续 prompt-crafter 以此为准，writer 通过 Prompt 接收按章提取的声音。文风原型只能作为形成阶段的讨论起点，确认后只保留项目自己的声音，不保留原型名称或来源印记。

本文件由作者**随时触发风格蒸馏更新**（上传样例文章 → 脱敏提取创作风格与文章结构 → 结合当前小说 → 生成/更新风格提示词），见文末「填写指引」与 `skills/planning.md`「风格蒸馏」。

## 总则：两部分的划分与消费

本文件分两个部分，**对应两种不同的消费方式**，不要混用：

- **第一部分 · 本书写作基调与创作逻辑**：回答"这本书为什么这么写"。它是全书/整卷级、逐章生效的创作决策依据——叙述视角、情绪外化的原则、信息差怎么管理、节奏怎么换气、群像怎么组织、事实怎么对齐。prompt-crafter 用它决定**「本章故事」怎么写**（叙述示范的视角与气质）与「必守事实与边界」里哪些是**创作逻辑约束**。
- **第二部分 · 写作技巧**：回答"这一句、这一场怎么写"。它是执行层的具体技法——句长、对白配比、感官密度、留白位置、章末落点与禁用表达。prompt-crafter 把它**逐场溶解**为「场景展开」各场的「本场声线」落点（句长倾向/配比/密度/留白/样句）。

判断归属的一句话标准：**写进章节叙述之前需要先决策的 → 第一部分；落笔时直接执行的 → 第二部分。** 例如"情绪不命名，靠动作顿挫"是创作逻辑（为什么），"动作段短句每句一个动作"是技巧（怎么写）。

**写法纪律**：两部分一律写成**可执行、无歧义的指示句**（"动作段用短句，每句一个动作"），不写抽象形容词（"生动、克制、高级"）——抽象词留给执行者的自由度过大，是声线漂移与质量波动的根源。基准样章与对照示范负责示范，其余各节负责锁死规则。

# 第一部分 · 本书写作基调与创作逻辑

## 1.1 写作基调

- 叙事者：{第几人称、限知/全知、叙事者与主角的距离}
- 整体语言气质：{一句话概括，如"冷硬短句底色上偶尔闪过诗意"；这句话是全章叙述示范的基调源头}
- 目标读者体感：{读者阅读时应有的情绪/节奏感受}
- 稳定与变化：
  - 必须稳定：{读者无论场景强弱都能辨认的句法、叙事距离、人物声音或留白习惯}
  - 可以变化：{随 POV、人物关系、场景压力和题材功能自然变化的节奏、感官和对白比例}
  - 不要把变化误判为漂移：{哪些差异是人物或场景需要，哪些变化才会破坏项目声线}

## 1.2 创作逻辑

每一条都是**章节创作的决策依据**：prompt-crafter 写「本章故事」与「必守事实与边界」时必须调用对应条；writer 通过 Prompt 接收其落点。按本项目实际需要填写，不需要的条目删掉，不要凑数。

- 情绪处理逻辑：{人物的情绪/内心如何被处理：命名还是外化？靠什么外化（动作顿挫/对白半句/停顿）？什么时候允许短暂直白？}
- 信息差管理逻辑：{谁在何时知道什么如何安排；信息差靠什么暴露（行动/对白/物件），不靠内心独白直说；什么信息对读者保密}
- 节奏逻辑：{生活质地与事件推进如何交替（呼吸与加压）；幕/章级的高低配；硬时钟事件（截止日期/公示/签约）如何锚定节奏}
- 群像组织逻辑：{配角/群像如何写活（有名字、有习惯、有利益）；群像戏避免什么（对白墙/脸谱化）；每个群体角色承担的叙事功能}
- 事实纪律：{时间、条款、数字等"硬事实"如何与时间线/设定对齐；正文不得含糊处理的约定}

## 1.3 文章结构

本项目从样例蒸馏出的可迁移结构写法（组织"发生什么"的方式，与声线正交；约束「本章故事」与各场叙述的组织方式）：

- **开篇切入**：{从什么画面/事件直接进场，不做什么铺垫}
- **场景推进**：{一场戏内部如何组织：进场→目标→阻力→反制→选择→余波；信息如何逐层给出}
- **转折节奏**：{变化发生在动作/对话/判断的哪一环，密度如何}
- **收束方式**：{章末如何停画面/留钩/换气}

# 第二部分 · 写作技巧

## 2.1 基准样章

以下是一段足以展示本项目声线的完整原创段落，长度以能看见声音、节奏和人物注意力为先。它是第二部分各节（对照示范/指示句/禁区）的语感来源：prompt-crafter 从中提取逐场落点（各场「本场声线」的句长/配比/密度/留白/样句）；writer 以 Prompt 内已经提取的声线材料为准。

> {粘贴或创作一段最能代表目标声线的正文。最好同时出现对白、动作/感官和内心活动；如果某种声线不需要其中一项，不要为了填齐而硬加。}

## 2.2 对照示范

用"这样写 / 不要这样写"成对呈现本项目最容易偏离的表达边界。通常覆盖对白、叙述和情绪三个维度；只写真正能帮助 writer 辨认声音的对照，不为凑数量制造坏例子。

### 对白
- 这样写：{符合声线的简短对白示例}
- 不要这样写：{常见偏离的简短对白示例}
- 原因：{一句话说明差异}

### 叙述/动作
- 这样写：{示例}
- 不要这样写：{示例}
- 原因：{差异}

### 情绪/内心
- 这样写：{示例}
- 不要这样写：{示例}
- 原因：{差异}

## 2.3 逐项指示句

每条都是落笔时直接执行的技法。prompt-crafter 按本章场景性质选取对应条溶解为「本场声线」；写不进的条目不要硬塞。

- **动作段**：{短句/长句；每句几个动作；动作与动作之间的顺序纪律}
- **对白**：{口语程度、方言/腔调使用、句长、信息怎么露（说半句/咽半句）}
- **情绪**：{命名还是外化；情绪用哪些动作顿挫来露（停了一下/手没伸/换手）}
- **感官**：{每章至少几处、落在哪些物/气味/触感上；禁止什么（成语/抽象概括）}
- **章末纪律**：{停在动作/画面/悬念/情绪中的哪种；禁止空升华和旁白预告}

## 2.4 声线禁区

本项目明确不使用的表达模式（与 anti-ai 的通用删改规则互补，这里是源头预防）：

- {禁区 1：如"不让明喻替人物完成本应发生的观察或行动"}
- {禁区 2：如"不用解释性对照句替人物下结论"}
- {禁区 3：如"不让内心说明打断仍在发生的动作"}
- {按需增加}

## 下游接口

| 消费者 | 消费方式 |
|---|---|
| prompt-crafter（「本章故事」） | 读第一部分 1.1/1.2/1.3：用基调与创作逻辑亲自书写本章叙述示范（视角、情绪外化、信息差暴露、节奏换气、结构组织）；叙述本身即 writer 拿到的第一声线示范 |
| prompt-crafter（「必守事实与边界」） | 读第一部分 1.2：创作逻辑约束（硬时钟、群像纪律、信息差边界）落入本章必守事实 |
| prompt-crafter（「场景展开」） | 读第二部分 2.1/2.2/2.3/2.4：按场次性质选取指示句与样句，溶解为各场「本场声线」落点（句长倾向/对白配比/感官密度/留白位置/一句样句）；禁区条目核入本章边界 |
| writer | 不回读本文件；只以 Prompt 内已提取的声线材料为唯一指令源 |
| Reader / anti-ai | 首读不预挂；追查根因或编辑模式时按需对照 2.2/2.4 辨认偏离 |

## 填写指引

本文件的产生与更新有两条路径，均由 volume-planner 执行、作者确认。填写时先按上述两部分的归属标准把每个特征放进正确部分。

**路径一：文风形成**（`outline.volume` 阶段，卷纲与文风一同确认）

1. 先请作者提供少量"最像目标声线"的正文（可以是作者旧作、参考作品片段或即兴试写）；参考作品只用于分析声线，不复制角色、情节或标志性句子。
2. 从样章中提炼：整体气质与叙事距离进 1.1；创作逻辑（情绪/信息差/节奏/群像/事实）进 1.2；结构写法进 1.3；句级技法进 2.3；边界进 2.2/2.4。
3. 对照示范必须来自真实句子，不用"应该更生动"等无法执行的描述。
4. 作者确认后锁定；后续卷如需微调，由 volume-planner 提出、作者确认，不静默修改。
5. 如果没有现成样本，不让模型自行猜测"高级、克制、爽利"等抽象方向；先针对同一小场景形成两种原创短试写，请作者选择，再把选择沉淀为样章和边界。

**路径二：风格蒸馏**（作者随时触发，可在项目任何阶段提出）

作者提出"蒸馏文风/上传样例文章/生成风格提示词/调整声线"时，执行四步蒸馏：

1. **脱敏提取**：通读作者上传的样例文章（旧作/参考片段/试写），提取可迁移风格特征——句法节奏、叙事距离、感官使用、对白关系、情绪处理、收束习惯；**删除全部来源印记**（作者名、作品名、角色名、世界观词、标志性比喻、可识别句式）。
2. **分层落位**：把提取到的特征按归属标准分入两个部分——创作逻辑（为什么这么写）进第一部分，执行技法（怎么写）进第二部分；结构写法进 1.3。
3. **结合适配**：对照 `genre-setting.md` 题材期待、`story.md` 主线与已接受正文（如有），把通用特征适配为当前小说专属；与题材或已接受正文冲突时由作者裁决。
4. **生成风格提示词**：把全部特征写成**可执行指示句**（不写抽象词），更新本文件对应节；样句/样章同步核验反 AI 纪律（零破折号、零否定对照、零情绪命名），违规即改写。交作者确认后锁定，`author_confirmed` 语义与卷纲确认一致。

蒸馏是增强而非门禁：作者未提出时，项目按既有两层提取流程工作；蒸馏后，prompt-crafter 以本文件的指示句为唯一声线依据，自由写但依据被锁定。
